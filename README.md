# wpf-analyse-contributions

**FR** — Application de bureau **WPF (C#)** d'analyse de **contributions** importées depuis un fichier **CSV** : agrégation, statistiques et affichage filtrable, avec interface bilingue.

**EN** — A **WPF (C#)** desktop app that analyzes **contributions** imported from a **CSV** file: aggregation, statistics and a filterable view, with a bilingual UI.

---

## Fonctionnalités / Features

- **FR**
  - Import et analyse d'un jeu de données CSV (`contributions.csv`).
  - Architecture **MVVM** avec convertisseurs (ex. booléen → Oui/Non).
  - Interface **bilingue** via ressources de traduction.
- **EN**
  - Import and analysis of a CSV dataset (`contributions.csv`).
  - **MVVM** architecture with value converters (e.g. boolean → Yes/No).
  - **Bilingual** UI via translation resources.

## Stack

C# · .NET · WPF · MVVM.

## Lancement / Run

```bash
# Ouvrir tpfred.sln dans Visual Studio 2022, puis F5
dotnet run
```
